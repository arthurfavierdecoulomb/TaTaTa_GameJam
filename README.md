# TaTaTa_GameJam
GameJam 2026


Titre : Die in the light


Contrôles : 

Q --> gauche
D --> droite
Espace --> sauter


Objectif : 
Le but est de s'échapper du manoir abandonné plongé dans le noir.
Muni d'une lampe torche vous devez traverser un parkour rempli de pièges afin de vous enfuir du manoir.

Thème : 
Fragile, horrifique.
